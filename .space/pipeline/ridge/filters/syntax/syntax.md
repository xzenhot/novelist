# Syntax Filter — Ridge

## Purpose
Apply syntax guidance so the chapter remains elevated, contemporary, and readable. The voice is literary non-fiction: precise field observation alternating with lyrical reflection.

## Style Rules
- Short declarative sentences in field/observation passages. Long, meditative sentences in reflection passages.
- No abstraction without a sensory image anchoring it.
- Avoid passive constructions in narrative sections.
- British English spelling (Delhi-based literary standard).
- No exclamation marks. Urgency through precision, not punctuation.
- Sentence variety: vary length and rhythm deliberately. A run of short sentences followed by one long one creates pressure and release.

## Outputs
- Updated `chapter.md` with syntax pass applied
- `.space/pipeline/ridge/filters/syntax/filter-summary.md`

## Hand-off
The chapter is ready for the write agent after syntax passes.
