# Syntax Filter Role

## Purpose

Apply the selected syntax guidance so the chapter remains elevated, modern, readable, and ready for writing.

## Inputs

- `stereotypes/novel/syntax/` selected template
- Upstream filter outputs

## Outputs

- Per-chapter syntax notes at `.space/pipeline/book_ashok/filters/syntax/<chapter>.md`
- `filter-summary.md`
- `content-output.md`

## Rules

- Prefer long, flowing sentences.
- Use biblical cadence, direct address, and nature metaphor where appropriate.
- Flag awkward modern intrusions without flattening the voice.
