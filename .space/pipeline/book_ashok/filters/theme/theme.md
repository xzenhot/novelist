# Theme Filter Role

## Purpose

Assign the chapter theme, theme essence, contemporary mapping, and form-consistent stereotype selection.

## Inputs

- `stereotypes/novel/themes/generic.md`
- Upstream filter outputs

## Outputs

- Per-chapter theme assignments at `.space/pipeline/book_ashok/filters/theme/<chapter>.md`
- `filter-summary.md`
- `content-output.md`

## Rules

- Cycle themes in order through the chapter list.
- Map each Stoic theme to Ashok's inner and political journey.
- Keep the signature (gibran) and reference (aurilus) consistent.
